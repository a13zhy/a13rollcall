## 💥 课堂真实痛点
- 👨‍🏫 **老师痛点**：点名选择困难，纠结选谁浪费课堂时间；很难直观看到哪位学生被抽查少、哪些课文抽查频次不足；缺少课堂轮次记录，课后无法复盘本节课抽查情况。
- 👩‍🎓 **学生痛点**：存在侥幸心理，指望永远不被点到；薄弱学生被抽到概率偏低；背诵练习缺少完整统计追溯。
- 📊 **旧版短板(V6.2)**：Tkinter界面老旧；缺少轮次历史记录；统计只有简单表格，无可视化图表；插件系统能力有限；部分设置项仅UI展示没有实际生效；缺少撤销重做、分组抽取等实用课堂能力。

**V6.8 针对性解决全部上述痛点。**

## 🚀 快速上手
### 环境依赖
- Python `3.9`及以上
- 依赖：`PyQt5`
```bash
pip install PyQt5
```

**运行程序**
```bash
# 主程序启动
python main_qt.py

# 新手配置向导
python wizard_launcher.py

# 可视化插件打包工具
python arcx_packager.py
```
> 运行后弹出GUI窗口，**非控制台操作**。

📦 不想安装Python：前往 [Releases](https://github.com/a13zhy/a13rollcall/releases) 下载打包好的EXE安装包，Windows直接双击使用。

### 班级数据准备
1. 旧版迁移：直接复制V6.2的`students.txt`、`texts.txt`到程序目录，启动自动加载。
2. 新建班级：
   - 在软件内「学生管理」批量粘贴名单，一行一名学生
   - 在「课文管理」添加抽背课文；不需要抽背则不添加课文，自动进入纯点名模式

## 💡 课堂使用小技巧
1. **分层教学**：新建学生分组，抽取时选择分组，只抽查该组学生。
2. **课后复盘**：打开统计窗口，查看本节课全部轮次记录、课文抽查统计，分析薄弱学生与薄弱篇目。
3. **投影上课**：开启暗色主题，开启界面缩放，适配教室大屏；打开悬浮小窗，不遮挡课件。
4. **纯点名模式**：不导入任何课文，系统自动关闭抽背，只做随机点名。
5. **插件扩展**：打开可视化插件打包工具，拖拽组件快速制作自定义功能插件，拓展软件能力。

> 避坑提醒：导入外部txt文件务必使用`UTF‑8`编码；名单、题库不要留多余空行。
