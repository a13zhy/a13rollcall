🛠️ 极速上手｜小白也能一秒玩转
一、运行环境
仅需 Python 3.8+，绿色纯净，无任何附加要求！
二、部署步骤
1. 克隆项目到本地
git clone https://github.com/a13zhy/a13rollcall.git
cd a13rollcall
2. 自定义专属数据
- students.txt：一行一个学生姓名，杜绝空行、多余空格，避免抽取bug
- texts.txt：一行一个题目/知识点，按需更新抽背内容
三、双启动模式｜按需任选
✅ 老手极速模式（直接开跑）
python main.py
✅ 小白向导模式（手把手教）
python wizard_launcher.py

⚙️ 高阶玩法｜解锁自定义新姿势
通过 config_manager.py 轻松解锁个性化设置，玩出专属风格：
- 开启去重抽取：避免同一个人连续“中奖”，主打一个雨露均沾
- 调整单次抽取人数：单人抽查、多人批量点名自由切换
- 自定义输出样式、提示文案，适配自己的使用习惯
- 自动过滤空数据、无效内容，杜绝程序翻车

---
💡 私藏玩法技巧｜老用户都在用
- 纯点名模式：清空 texts.txt，程序自动关闭抽背功能，专注课堂提问
- 全员速查模式：关闭去重规则，适合随堂快速全员抽查，高效不拖沓
- 避坑小Tips：所有文本文件统一使用UTF-8编码，杜绝中文乱码；名单不要留空行，避免无效抽取
- 懒人终极方案：直接下载Release打包版本，不用装Python，双击就能用！
